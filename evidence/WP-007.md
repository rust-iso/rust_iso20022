## Semantics and non-claims

- IBAN validates canonical syntax, national BBAN structure, and MOD-97.
- BIC/BICFI validates ISO 9362 syntax and the ISO country component.
- LEI validates syntax and MOD-97.
- Explicit APIs report that account existence, BIC directory membership, and
  LEI directory issuance/status were not verified.
- `financial_rules()` exposes 22 executable L2 rule objects; execution and
  explanation share the same registry and diagnostics never contain values.
- Helper-to-`String` and `Money::into_parts` conversions feed generated leaf
  fields; no helper represents an ISO 20022 message.
