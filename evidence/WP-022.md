# WP-022 Bounded MT Parsing and Mapping Framework Evidence

## Status

**Done — T137–T142 complete.**

## Red phase

Before the migration crate existed, parser/report contracts had no target. The
first executed parser suite then found one faulty privacy assertion in the test:
an empty input is mathematically a substring of every diagnostic. The assertion
was narrowed to non-empty inputs; typed empty-input behavior stayed covered.
All implementation assertions then passed without weakening parser limits.

## Implemented scope

- `MtDocument` is a bounded transient MT syntax tree, explicitly not an ISO
  20022 canonical model. Specific conversions must return generated structs.
- The parser preserves ordered top-level blocks, block-4 tags, continuation
  lines, duplicate tag occurrences, UTF-8 values, and byte source spans.
- It rejects empty/malformed structure, invalid blocks/tags, duplicate or
  misordered blocks, missing block 4, and all configured limit violations with
  typed errors that never contain source values.
- Six finite dimensions are enforced: 1 MiB input, nesting depth 8, 16 blocks,
  512 fields, 64 KiB per field, and 256 continuation lines per field.
- `MappingReport::build` requires exactly one source entry for every parsed
  field. Missing, duplicate, unknown, and tag/occurrence/span-mismatched sources
  are typed failures.
- The five classifications are `Exact`, `Derived`, `Lossy`, `Ambiguous`, and
  `Unsupported`. Ambiguous/unsupported entries populate `unmapped_fields`.
- Entries and warnings are deterministic. Serialized reports contain source
  index/tag/occurrence/span and value-free rationale, never MT field content.

## Corpus and boundary evidence

The representative MT input contains blocks 1–5, nested block-3 metadata,
fields `20`, `32A`, `50K`, duplicate `71A`, a multiline continuation, an IBAN,
and Japanese text. Tests also cover truncated blocks, malformed tags, text
outside fields, block order, duplicate blocks, absence of block 4, arbitrary
Unicode inputs, all six exact resource limits, all five mapping classes, and
every report-accounting failure.
