# WP-031 — Complete SDK Documentation

## Outcome

The public documentation now distinguishes implemented capabilities from
planned profile coverage. Generated structs remain the canonical model and are
explicitly described as accessible alongside additive high-level APIs.

## Public documentation coverage

- Root API and public hand-written modules document generated access, builders,
  catalogue/metadata, validation, profiles, helpers, privacy, and version
  comparison.
- The CLI, MCP, migration, WASM, and benchmark workspace crates have crate- or
  module-level documentation on their public modules.
- Generated family/message modules remain generator-owned. Their public access
  contract and feature selection are documented in `src/lib.rs`,
  `docs/model-features.md`, and `docs/feature-matrix.md`; generated output was
  not manually patched for this work package.
- Public library failures use domain error types. Adapter-only presentation and
  exit-code behavior are documented in `docs/cli.md`, `docs/mcp.md`, and
  `docs/wasm.md`.
