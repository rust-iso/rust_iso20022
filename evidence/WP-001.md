`generated::any::AnyMessage` had no `Document` variants. The fix adds internal
`__message_model` feature gating: header types remain accessible with
`model-head`, while `AnyMessage` is generated only for families that actually
contain `Document` messages. The same condition is emitted by codegen rather
than being a manual generated-only patch.
