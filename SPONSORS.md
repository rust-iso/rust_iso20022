# Sponsorship

## Using rust_iso20022 in production?

Support long-term standards maintenance at [Ko-fi](https://ko-fi.com/jnz).
Sponsorship funds work that is difficult to sustain through one-off feature
contributions:

- ISO schema updates and reproducible code generation;
- annual CBPR+ and SEPA source review and rule updates;
- additional network profiles and migration mappings;
- parser security, fuzzing, privacy review, and incident response;
- documentation, examples, compatibility work, and release maintenance.

The generated models, SDK core, validation framework, and implemented profile
rules remain open source. Sponsorship does not unlock a private canonical model,
closed validation rules, or preferential claims of bank/network acceptance.

Organizations may sponsor maintenance priorities, fixtures, or research. Any
result merged into this repository must meet the same provenance, licensing,
review, test, evidence, and compatibility requirements as other contributions.
Restricted standards documents must not be uploaded or redistributed without
clear rights.
